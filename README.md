## PROJETO DE E-COMMERCE (QA_SHOP)

## Versão PT-BR

O QA_Shop é um projeto open source de e-commerce desenvolvido para apoiar o aprendizado de iniciantes em desenvolvimento e Quality Assurance (QA), proporcionando experiências práticas com testes de software, automação e qualidade de aplicações. 

Desenvolvido com as linguagens de front-end: HTML (HyperText Markup Language) - (Linguagem de Marcação de Hipertexto) , CSS (Cascading Style Sheets) - (Folhas de Estilo em Cascata) e a linguagem de programação JavaScript.


## Version English (EN)

QA_Shop is an open-source e-commerce project created to help beginners in Software Development and Quality Assurance (QA) gain practical experience with software testing, test automation, and quality assurance processes.

Built using front-end technologies including HTML (HyperText Markup Language), CSS (Cascading Style Sheets), and JavaScript, providing a solid foundation for modern web development.
